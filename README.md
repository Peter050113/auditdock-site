# AuditDock GitHub Pages Site

This repository contains the public pages required for App Store submission:

- `index.html`
- `privacy.html`
- `support.html`
- `styles.css`

Public URLs:

```text
Marketing URL: https://peter050113.github.io/auditdock-site/
Privacy Policy URL: https://peter050113.github.io/auditdock-site/privacy.html
Support URL: https://peter050113.github.io/auditdock-site/support.html
```

The pages describe AuditDock as a local-first working paper assistant and include support, data deletion, subscription restore, and privacy information for App Store review.
